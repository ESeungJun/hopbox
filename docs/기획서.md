## 한 줄 소개

맥·윈도우의 전체화면과 데스크톱 사이를 오가는 작은 택배상자. 한 화면에서 파일·글·이미지를 담고, 다른 화면에서 단축키를 누르면 거기 그대로 있다.

## 왜 만들었나

- 맥에서 전체화면 앱을 데스크톱마다 하나씩 띄워 놓고 일한다.
- 다른 화면의 파일을 Slack에 첨부하거나 스크린샷을 옮기려고 끌면, 마우스가 화면 끝에 막혀 드래그가 끊긴다.
- 그래서 매번 전체화면을 풀고, 창을 늘어놓고, 옮기고, 다시 전체화면으로 돌아갔다. 하루에 몇 번씩.
- 근거: 개발 글 [velog](https://velog.io/@haul/hopbox-parcel-box-between-fullscreen-spaces)(`dev-post/08-hopbox/post.md`), [README.ko.md](../README.ko.md)

## 누가 쓰나

- 맥에서 전체화면 앱을 여러 데스크톱(Spaces)에 띄워 놓고 일하는 사람.
- 윈도우에서 가상 데스크톱이나 전체화면 창을 오가며 일하는 사람.

## 목표

개발 글의 목표 표(`dev-post/08-hopbox/tables/tables.html`)를 옮긴다.

| 목표 | 결정 | 이유 |
|---|---|---|
| 전체화면을 깨지 않게 | 포커스를 뺏지 않는 떠 있는 창 | 상자를 부를 때마다 전체화면이 풀리면 만든 의미가 없다 |
| | 단축키 하나로 지금 화면에 배달 | 어느 데스크톱에 있든 같은 상자가 와야 한다 |
| 내 파일은 안전하게 | 끌어낼 때는 항상 복사 | Finder로 끌었다가 원본이 옮겨지면 안 된다 |
| | 파일은 원본을 가리키고, 임시 파일만 복사 | 용량은 안 늘리되 곧 지워지는 스크린샷 미리보기·메신저 파일은 지킨다 |
| 알아서 담되 함부로 담지 않게 | 스크린샷·복사한 이미지 자동 담기를 따로 켜고 끄기 | 필요한 사람도 있고 싫은 사람도 있다 |
| | 비밀번호 관리자 값·엑셀 셀은 안 담기 | 자동 담기가 민감한 값을 디스크에 남기면 안 된다 |
| 택배 받는 느낌 | 창은 그대로, 그림만 내려앉기 | 창 자체를 떨어뜨렸더니 튀는 게 버그처럼 보였다 |
| | 펼쳐도 상자 자리는 고정 | 열 때마다 아이콘이 움찔하면 손이 따라가기 불편하다 |

## 핵심 시나리오

1. 어디서든 **⌃⌥B**(윈도우 **Ctrl+Alt+B**)를 누른다. 전체화면 앱 위에서도 마우스 옆으로 상자가 떨어진다.
2. 파일을 상자에 끌어다 놓거나, 복사한 글·이미지·파일을 **⌘V**(**Ctrl+V**)로 담는다.
3. 다른 데스크톱으로 가서 단축키를 다시 누르면 같은 상자가 그 화면으로 온다.
4. 상자를 누르면 Dock 스택처럼 부채꼴로 펼쳐진다. 항목을 끌어서 첨부하거나 눌러서 복사한다.
5. 스크린샷을 찍으면 따로 담지 않아도 상자에 들어가 있다.

### 나중

- 윈도우 코드 서명: README에 "아직 코드 서명을 하지 않아서 SmartScreen 경고가 뜰 수 있다"고 적혀 있다.

### 범위 밖

- 원본 파일 옮기기: 꺼낼 때는 늘 복사다. 원본은 건드리지 않는다.
- 파일을 상자에 복사해 두기(일반 파일): 용량을 늘리지 않으려고 원본 경로만 가리킨다. 곧 지워질 임시 파일과 붙여넣은 이미지만 보관한다.
- 기기 사이 동기화·클라우드: 코드에 없다. 상자는 한 컴퓨터 안에서만 쓴다.
- 손쉬운 사용·화면 기록 같은 추가 권한 요구: 권한 없이 동작하는 방식만 쓴다.
- Linux: 맥(Swift)과 윈도우(WPF)만 있다.

## 완료·성공 기준

- 상자를 불러도 전체화면이 풀리거나 다른 데스크톱으로 넘어가지 않는다.
- 브라우저·Slack·스크린샷 미리보기에서 이미지를 복사·끌기 했을 때 이미지로 담긴다(개발 글의 앱별 확인 표).
- 끌어낸 파일의 원본은 그 자리에 남아 있다.
- 윈도우: `dotnet test` 통과(2026-11-05 기준 시험 27개, [ShelfStoreTests.cs](../windows/Hopbox.Windows.Tests/ShelfStoreTests.cs)), CI에서 앱을 켜서 상자를 부르고 6초+3초 동안 안 꺼지는지, `error.log`가 안 생기는지 확인([windows.yml](../.github/workflows/windows.yml)).
- 맥은 자동 시험이 없다. 화면 밖에서 그려 보고 확인하는 방식으로 상자가 열리고 펼쳐지는 모습을 확인했다(개발 글).
- 사용자 수·다운로드 수 같은 지표는 근거 자료가 없어 적지 않는다.
